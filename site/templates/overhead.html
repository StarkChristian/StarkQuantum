What this assumes

The logical error rate per round is taken as pL=0.1(p/pth)(d+1)/2, with the threshold pth=1% and code distance d. One rotated surface-code patch uses 2d2−1 physical qubits. The form follows Fowler et al., Surface codes: towards practical large-scale quantum computation (arXiv:1208.0928).

It leaves out everything that makes a machine expensive: noise that is not uniform, a decoder that must keep up with the measurement cycle, routing between patches, and the factories that supply magic states. Real estimates run well above this number. Treat the result as the cheapest case, and see resource estimate for how the published ones are built.

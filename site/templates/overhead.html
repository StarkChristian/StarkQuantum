What this assumes

For an odd code distance d, the logical error rate per round is taken as pL=A(p/pth)(d+1)/2, where p is the physical error rate and A and pth are constants fitted to simulations. One rotated surface-code patch uses 2d2−1 physical qubits: d2 for data and d2−1 for checks.

Three sets of constants are offered.

  • Fowler et al. 2012. A = 0.03 and a threshold of 0.57%, equation 11 and the threshold in arXiv:1208.0928, fitted to their circuit-level simulations.
  • This site's simulation. A = {{ t.fit_a }} and a threshold of {{ (t.fit_pth * 100) | round(2) }}%, from the simulation on the threshold page. The fit reproduces the points used to within a factor of about {{ t.fit_spread }}, and the best-fit A falls as the distance grows, so treat it as a rough guide.
  • Rule of thumb. A = 0.1 and a threshold of 1%. It is common in back-of-envelope estimates and has no single published derivation, so it is a round-number assumption.

These are empirical fits to specific noise models, not laws, and none is a property of a machine.

The estimate leaves out everything that makes a machine expensive: noise that is not uniform, a decoder that must keep up with the measurement cycle, routing between patches, and the factories that supply magic states. Real estimates run well above this number. Treat the result as the cheapest case, and see resource estimate for how the published ones are built.

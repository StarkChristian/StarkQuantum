What it uses

  • Static pages. Every page is generated at build time from Markdown, with Python and Jinja2. No server code runs when you read a page.
  • Hosting. Cloudflare Pages, built from a public GitHub repository.
  • Type. Source Serif 4 and Inter, as self-hosted variable fonts. Nothing is fetched from a font service.
  • Modern CSS. OKLCH colours, light-dark(), color-mix(), text-wrap: pretty, scroll-driven animation for the reading bar, and cross-document view transitions. Each one is optional: a browser that lacks it shows the page without it.
  • Mathematics. MathML, drawn by the browser. There is no maths script.
  • Charts and figures. SVG generated at build time from data, such as the threshold simulation run with Stim, Sinter and PyMatching. The data and the script are published.
  • Search. Pagefind, an index stored as static files and searched inside your browser. Your queries are not sent anywhere.
  • Definitions on hover. The Popover API shows a glossary entry when you point at a term.
  • Prefetching. Speculation rules fetch a page you are about to open.
  • Security. HTTPS only, a Content-Security-Policy that allows scripts only from this site and the statistics host, and a restrictive Permissions-Policy.
  • For machines. A plain Markdown copy of every page, an llms.txt index, RSS and JSON feeds, schema.org data, and citation meta tags on essays.
  • Reading. Semantic HTML, a skip link, keyboard-operable controls, reduced-motion support and a print stylesheet.

What it does not use

No advertising, no third-party trackers, no cookies, no client-side framework, and no font or script from a content network. The one script that is not served from this site is the visit counter described above.

Claims about the technology

The sizes above are computed by the build and change with the pages. The list is of what the site does today; it is not a claim of conformance to any accessibility standard, which would need an audit. Numbers and sources for the content itself are on the claims register.

---
term: Threshold
slug: threshold
---

The physical error rate below which error correction starts to help. Below it,
adding physical qubits to a logical qubit lowers the logical error rate. Above
it, the same addition raises it.

The threshold is a sign change, not a gradient, which is why *below threshold*
is the phrase to look for in any error-correction result. For the surface code
it sits near one per cent per operation, depending on the noise model and the
decoder.

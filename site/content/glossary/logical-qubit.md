---
term: Logical qubit
slug: logical-qubit
---

One unit of quantum information encoded across many physical qubits, protected
by error correction that detects and fixes errors while the computation runs.

The term is used loosely. It can mean an encoded state that was prepared and
measured, a memory that outperformed its physical parts, a memory that improves
as the code grows, or a qubit that actually participates in logical operations.
Only the last is computation. Ask which is meant.

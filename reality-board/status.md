# Reality Board

Last reviewed: 24 September 2026

Four plain questions about where quantum computing actually stands. Each status is a judgement from primary sources, and it changes only when new evidence is published and checked.

| Question | Status |
|----------|--------|
| Stable, repeated error correction below threshold | Early |
| Logical qubits with useful operations | Early |
| Advantage on a scientific or industrial problem someone actually has | Not yet |
| Fault-tolerant machine at useful scale | Not yet |

## Status labels

| Label | Meaning |
|-------|---------|
| Not yet | No credible, independently checkable demonstration exists. |
| Early | First demonstrations exist, at small scale or under narrow conditions, and are not yet stable or repeated. |
| Emerging | Repeated by more than one group, with improving trends, but not yet routine. |
| Established | Reproducible, routine, and used by people outside the group that built it. |

## Notes on each question

**Stable, repeated error correction below threshold.** Experiments have shown the logical error rate falling as code size grows. These are small codes, a limited number of rounds, and a few groups. The step from a demonstration to a stable, repeatable capability is not complete.

**Logical qubits with useful operations.** Keeping a logical qubit alive is not the same as computing with it. Logical gates, magic state preparation and logical measurement have been shown in pieces, not yet as a sustained computation.

**Advantage on a problem someone actually has.** Benchmarks designed to be hard for classical computers do not count here. The criterion is a scientific or industrial problem that someone needs solved, with the best classical method tried fairly.

**Fault-tolerant machine at useful scale.** This requires many logical qubits, low logical error rates, fast decoding and a long sequence of operations. Published roadmaps exist. A roadmap is a plan, not a result.

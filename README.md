# StarkQuantum

Independent notes on quantum hardware and error correction.  
Reality over hype.

**Website:** [starkquantum.com](https://starkquantum.com)

---

## What this is

Stark Quantum is a personal project that reads primary sources, separates claims from evidence, and writes down what is still missing.

- A demo is not a machine.
- A physical qubit is not a logical qubit.
- A press release is not evidence.

No vendor affiliation. Nothing for sale.
